# 绘图后校对增强规格

来源：用户确认的十张工单；先发布至 GitHub，再按任务图实施。每票验收包括真实可观察行为、正例与故意损坏的负例。

测试边界已由用户批准的各票验收标准确认：独立校核 CLI、完整驱动器 CLI、生成的 SVG/PNG/追溯清单/报告。禁止以修改私有实现后同算法重算期望值代替行为测试。

实施依赖补充：#65 的可见连接、#67 的可见红圈以及 #69 的文字实际范围均须复用 #68 的浏览器显示证据采集器，核对最终 CSS 与变换；缺少实际显示证据时明确未校核。对应 GitHub 原生依赖已同步。

## 01 · #64 逐端口检查旋转后的接管位置与方向

https://github.com/sbhorshy/hydraulic-schematics/issues/64

Blocked by: None

生成一张含旋转、缩放符号的 L0 图后，逐个核对管线实际接入的端口、进出方向及本体避让，并在报告和局部定位中明确标出断口、穿本体或越界线头。

- [ ] 以实际使用符号的端口和图元变换为真值，覆盖四种正交旋转、等比缩放、非零 viewBox 原点及现有画布偏移；端口、本体足迹和检查位置使用同一坐标系。必要的几何归一化先在本票完成，并以可复用边界供后续校核使用。
- [ ] 首末段方向与旋转后的锚向一致；端点准确抵达目标端口。容差显式记录，不能通过扩大容差吞掉可见断口或线头。
- [ ] 将已修复的防火墙关断活门到 EDP 的短净距接管作为正例；故意偏移端点、反向入射、恢复六像素折返的负例均阻断通过。
- [ ] 检查实际接管全段是否穿越非目标本体，避免仅因某端点与任意边界坐标接近而豁免整段。
- [ ] 错误至少返回组件、端口、连接锚点及定位坐标；直接校核和驱动器给出一致结果。
- [ ] 不根据元件朝向或目标位置更换输入声明的端口，不改变现有输入拓扑；原有基准回归通过。

相关已有工单 #62 负责旋转后的走线避让，本票负责独立校核，不重复实现其路由策略，也不以其完成为前置条件。兼容现有坐标契约，#23 的契约迁移不阻塞本票。

## 02 · #65 逐边追溯并阻断漏连、多连和错连

https://github.com/sbhorshy/hydraulic-schematics/issues/65

Blocked by: #64, #68

从唯一 L0 输入生成图与追溯清单后，系统逐条验证图上实际连接的两端与输入一致；即使连接总数相同，错接设备、端口或母线也会被拦截。

- [ ] 规范生成链自动给节点、端口、路径分段、taps 和母线提供可解析的输入锚点及追溯清单，不依赖针对单张图的补充脚本。
- [ ] 定义母线合并、跨线桥拆段和裸实例 main_path 展开的规范对账方式；一条逻辑连接绘成多段时不会误判为多连。
- [ ] 从可见 SVG 几何及已校核端口建立实际连接关系，与输入对账；不能仅相信图元上自报的 data-edge 或比较总数量。
- [ ] 删一条连接、添加一条连接、交换两个目标端口但保持边数不变、将支路移挂错误母线四类负例均失败并定位到输入锚点。
- [ ] 节点/端口/边的锚点缺失、重复或引用不到输入时明确报告；概念图中声明为 unknown 的连接不会被自动补画。
- [ ] 正例包含串联、分支、两泵并联、母线和气侧 taps；驱动器输出与独立校核一致，并保留 SysML 链已有行为。

## 03 · #66 按真实连通关系校核交叉、三通和跨线桥

https://github.com/sbhorshy/hydraulic-schematics/issues/66

Blocked by: #65

读图时能可靠区分真实汇流、普通拐角和不连通交叉；点或跨线桥画错位置时，系统给出可定位的失败。

- [ ] 依据已对账的网络关系核对连通点，不能仅凭三通点是否落在某个母线 x 坐标上作结论。
- [ ] 真实三通位于主线直段与支路汇合处；缺点、偏点、在普通二度拐角加点等情况有明确判断。
- [ ] 不同网络交叉须使用规定的不连通表示，且不能误加连接点；真实连接不得被跨线桥割断。
- [ ] 跨线桥位置与实际交叉一致，桥拱和管线连续，图上的连接关系与输入保持一致。
- [ ] 图例示例点、符号内部节点、系统管网节点分开识别；图例中的示例三通不再触发系统母线告警。
- [ ] 为正确 T 形连接、不连通交叉及每种误画建立正负例；报告包含涉及的两条连接和交点坐标。

## 04 · #67 让 taps、悬空口清单、红圈和图签一致

https://github.com/sbhorshy/hydraulic-schematics/issues/67

Blocked by: #68

完成出图后，悬空口报告只列真正未接的端口，并与红圈和图签计数一致；已连接的气侧测量支路不会继续误报悬空。

- [ ] 使用集合覆盖 paths、main_path 展开和 taps 两端，正确处理 gas/measurement/body_tap 等已有语义。
- [ ] 以当前 1# 图为回归，蓄压器—充气活门—压力表中已接的气侧端口不再被当成悬空。
- [ ] 报告、图签、可见红圈使用一致的未接端口集合；预期开放的地面接头与未建模的驱动口等沿原定义披露。
- [ ] 目录声明端口与实际采用的符号端口不一致时，单独报告契约差异，不通过忽略缺口制造计数一致。
- [ ] 删除一个 tap、漏画一个已声明连接的端口标记以及破坏本地符号端口组时，正反例能区分输入未接、绘图漏接和资产契约不一致。
- [ ] 独立校核和完整驱动链结果一致；图签计数变化可在最新 PNG 中核对。

## 05 · #68 检查所有外接引线的实际显示线宽

https://github.com/sbhorshy/hydraulic-schematics/issues/68

Blocked by: None

生成图中外接引线与相邻管网保持规定的有效线宽；无论使用 line、path 或 polyline，换一种 SVG 表达都不能让同一线宽错误逃过校核。

- [ ] 延续已确认的画法：外接引线跟随所在管网，阀体轮廓和内部机构保持各自规定线宽；不将整个符号统一加粗。
- [ ] 覆盖现有库使用的常见直线引线表达、CSS 类/继承/内联覆盖和嵌套变换，检查最终有效线宽而非只查看 class 名或 stroke-width 字面值。
- [ ] 结合相接管线类别、端口身份及符号边界核对线宽连续性；只允许在定义好的边界变宽，不允许在空白引线上突变。
- [ ] 以优先阀、油滤、泵、旋转优先阀建立正例；端口引线恢复轮廓宽度、覆盖 CSS、引入额外缩放等负例均失败。
- [ ] 在正常倍率及放大输出中核对线宽比例；像素比较允许明确的抗锯齿容差，不要求每列黑像素数完全相同。
- [ ] 不支持的 SVG 构造或缺少实际显示证据时明确列为未校核并说明对象，不能计为通过；每个失败附接点或局部图定位。

## 06 · #69 用实际文字边界校核净空、重叠和裁切

https://github.com/sbhorshy/hydraulic-schematics/issues/69

Blocked by: #68

图纸生成后能发现压字、文字出框、图签截断和标签净空不足，并提供对应文字和区域的定位。

- [ ] 使用与最终图一致的字体和渲染结果取得文字实际范围，支持多行文本、文本锚点及旋转/缩放后的标签。
- [ ] 检查文字与管线、元件轮廓、其他文字之间的净空，实施现有 B7 标签净空规则；图例、图签、边界文字和用户框均纳入。
- [ ] 文字越出自身容器或画布时报告，即使文字基点和元件声明框仍在画布内也不能放过。
- [ ] 曾出现的长图签截断作为负例，三行图签作为正例；同时覆盖中文、多行用户名和字体替换造成的尺寸变化。
- [ ] 报告给出文字、实际包围盒、冲突对象和差额；不使用缩小字号作为自动通关手段。
- [ ] 测量不可用时显式未校核；一次取得文字范围供本轮所有相关检查复用，避免逐标签启动浏览器。

## 07 · #70 按实际足迹和真实折点校核布局余量

https://github.com/sbhorshy/hydraulic-schematics/issues/70

Blocked by: #64

旋转后的元件和管线具有可读的实际间距；连续直线中的存储切分点不会被误报为短管段。

- [ ] 元件净距统一使用变换后的足迹，补齐现有 B6 管线避让走廊检查，并按已有 B5/B6 数值口径报告实测差额。
- [ ] B4 最短线段统计先在同一逻辑连接内合并共线连续分段，保留真实转折、分支、接口和有语义的断点。
- [ ] 将一条直线任意拆成多个连续共线 SVG 段，不改变 B4 结论；真正短折返、短折角和贴体走线仍被发现。
- [ ] 覆盖非正方形符号的 90°/270° 旋转，避免使用未旋转声明框产生错判；错误消息附距离最近的对象及位置。
- [ ] 警告与失败级别沿当前成熟度约定明确披露，不通过放宽阈值或扩大例外消除告警。
- [ ] 正反例及原有图样回归通过；通用几何测量复用第一票的归一化结果。

与 #23 的 drawable/画布边距迁移兼容，但本票不迁移坐标契约。装配成员及围框语义的新增能力由已有 #39 负责。

## 08 · #71 让校核与回读结论绑定当前图纸版本

https://github.com/sbhorshy/hydraulic-schematics/issues/71

Blocked by: None

用户能看到当前这张图实际完成了哪些检查；输入或图像改变后，旧的通过/回读结论自动失效，缺失检查不会混入“零失败”。

- [ ] 建立检查覆盖清单，每个适用检查有通过、失败、提示、未校核等明确状态及证据；不适用须说明原因。
- [ ] 输入定义、布局、实际使用的目录/符号、相关工具版本、SVG 和 PNG 具有内容指纹或等价版本标识，报告与感知回读记录绑定这些产物。
- [ ] 只改变 SVG、替换同名旧 PNG、修改符号或布局后，旧回读状态不能继续表示当前版本已确认；仅检查文件存在或时间戳不足以通过。
- [ ] 缺回读图、缺少必要测量能力或存在未完成的必检项时，完整驱动器不能宣告交付通过；自动校核完成与人工感知回读完成分别显示。
- [ ] 报告保留现有消费者所需字段并提供兼容迁移；无须改变原有输入定义即可运行。
- [ ] 通过篡改/替换产物的负例验证失效机制；未变化的产物可复用证据，但不会因此跳过必要的新版本校核。

## 09 · #72 自动生成接点和交叉区域的放大回读清单

https://github.com/sbhorshy/hydraulic-schematics/issues/72

- [ ] 从本轮最终 PNG 自动裁取所有外接端口、系统三通/交叉点、复杂复合符号和自动校核疑点；每项保留足够上下文。
- [ ] 局部图附组件、端口/连接标识和全图位置，可跳回整图对应区域；合理合并相邻区域但保留每个对象的覆盖记录。
- [ ] 完整图显示布局、文字和图例；局部图显示线宽、微小断口、越界线头、符号方向等细节。
- [ ] 一次完整栅格化后批量裁图，不为每个接点重新启动转换器；输出耗时和局部图数量可见。
- [ ] 回读结果绑定本轮图像版本；生成局部图本身不能自动将感知回读标为完成，记录已确认、存疑及未查看项。
- [ ] 用优先阀线宽与防火墙关断活门线头的历史缺陷证明目标区域会被收录并可辨识。

## 10 · #73 校核局部修改的预期影响与图像差分

https://github.com/sbhorshy/hydraulic-schematics/issues/73

Blocked by: #65, #71

修复局部图形后，报告哪些节点、连接和像素区域实际发生变化，并指出超出声明影响范围的变化，帮助发现修一处带坏另一处。

- [ ] 对两个可比版本同时比较输入锚点/连接关系和渲染结果，输出变化对象与图像差分定位。
- [ ] 允许为本次修改声明目标对象及其合理关联影响；例如旋转一个符号可以影响相连管线，不以固定裁剪框盲目判断。
- [ ] 局部线宽或线头修复的示例中，能证明拓扑未变，并定位视觉变化；修改另一只元件或意外换口的负例会被指出。
- [ ] 全局布局、画布或字体变化可明确声明为整体变化；无法可靠对齐的版本说明不可比较，不能输出无差异。
- [ ] 差分必须使用版本已核实的 SVG/PNG；抗锯齿容差和比较范围可见，不能用大面积遮罩隐藏真实变化。
- [ ] 保留独立完整校核，差分通过不替代几何/端口/回读检查；报告给出可复现的正负例及比较耗时。
