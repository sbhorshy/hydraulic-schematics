# Triage labels

五个标准角色映射如下；技能提到角色时使用对应标签。

| 标准角色 | GitHub 标签 | 含义 |
|---|---|---|
| needs-triage | needs-triage | 待维护者分拣 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格齐全，可由代理执行 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

已有 `wayfinder:*` 标签表示地图或工作类型，与上述分拣角色并存。修改映射时更新本文件；创建标签前先检查是否存在，保留已有标签的用途及描述。
