# 液压原理图语义模型：领域词汇表

## System Intent（系统意图）

工程师以自然语言提供的系统边界、组件、主油路、测量/控制关系及明确未知项。系统意图是生成草案的证据，不是已确认拓扑事实。

## Semantic Claim（语义声明）

从系统意图中提取的一条可引用声明，具有稳定 ID、原文和分类。分类为 `explicit` 时表示原文明确陈述；分类为 `catalog_inference` 时表示由已批准组件目录得出。

## L2 Model（L2 语义模型）

经工程师审查确认的系统组件、装配、网络、仪表关系和功能关系的权威拓扑模型。它不包含坐标、走线或图形样式。

## Net（网络）

同一介质和管路语义下彼此流体相通的一组端口。网络表示物理连通，不表示阀的允许通流方向、仪表测量意图或布局位置。

## Instrumentation Relationship（仪表关系）

传感器的指定端口经指定网络测量一个目标成员端口的指定位置，例如“压力开关经入口网络测量单向阀入口侧压力”。它不是主油路串联关系。

## Functional Relationship（功能关系）

不依赖图形相邻的组件功能语义，例如单向阀阻断反向流、溢流阀泄放。它不取代网络中的端口连通事实。

## Assembly Component（装配组件）

作为一个系统组件对外暴露公开端口、在内部封装本地成员及内部网络的复合组件。外部网络只能连接公开端口，不能直接连接本地成员。

## Published Port（公开端口）

装配组件的外部接口。每个公开端口映射到唯一内部网络，但装配虚线边界本身不是连接节点。

## Review Card（审查卡）

由草案 JSON 自动派生的组件、网络、仪表、功能和待决项表。工程师通过确认、修改或标记未知来审查模型，而非逐项编辑 JSON。
